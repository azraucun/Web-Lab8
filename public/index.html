Web Development Programme

A made-up study programme, served by a small Express server.

About the programme

The Web Development Programme is a fictional two-year course that teaches students how the web works from both sides: the browser and the server.

Students start with HTML, CSS and JavaScript, move on to React, and then build their own back-ends with Node.js and Express. This page is served by such a back-end.
